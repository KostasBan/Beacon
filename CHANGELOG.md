# Changelog

## 0.1.0 - Package Foundation

- Converted Beacon to a root-level Unity Package Manager package.
- Aligned package identity with the Lens package family.
- Added runtime config repository, source, store, validation, and snapshot abstractions.
- Added local `TextAsset` config loading and HTTP config loading with ETag support.
- Added last-known-good disk fallback.
- Added typed config value access and JSON feature flag evaluation.
- Added deterministic rollout, platform targeting, app-version targeting, and kill switch support.
- Added editor debug tooling, sample scene, package docs, CI workflows, and release workflow.
